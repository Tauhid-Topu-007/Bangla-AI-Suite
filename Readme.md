# 🇧🇩 Bangla AI All-in-One Suite  
**12 Powerful AI Tools Combined — Complete Bengali AI Platform**  
Built with **FastAPI**, fully optimized for Bangla text, documents, NLP & date systems.

---

## 🚀 Features (What This API Can Do)

### 📅 1. Bangla Date System
- English → Bangla number conversion  
- Bangla year, month, day calculation  
- Season detection (e.g., গ্রীষ্ম, বর্ষা, বসন্ত…)  
- Bangla day names  
- Dynamic greetings (শুভ সকাল, শুভ রাত্রি, etc.)

---

### 🔤 2. Bangla NLP Utilities
- Stop-word filtering  
- Word cleaning & normalization  
- Word frequency estimation  
- Hashing / unique ID generator  
- Emoji-supported greeting  
- Similar word analysis (if implemented later)

---

### 📄 3. File & Document Processing
- Upload and analyze text files  
- PDF support (optional via PyPDF2)  
- Line count, word count, Bangla-only filtering  

---

### ⚙️ 4. Technical Features
- FastAPI router + auto docs  
- CORS enabled  
- Handles JSON, text, files  
- Clean error handling
